SuhanaSaath website prototype

HOW TO VIEW
1. Extract this ZIP.
2. Open index.html in a modern browser.

IMPORTANT LIMITATIONS
- This is a front-end prototype, not a live matchmaking website.
- The signup form validates locally but does not send or store any data.
- Private chat, real member accounts, identity checks, moderation, and bookings are not connected.
- Profile cards are demo placeholders and must not be presented as real members.
- The hero concept image is included in assets/.
- Some profile demo photos use remote Unsplash URLs and need internet to display.
- Before launch, add secure backend/authentication, privacy policy, consent flows, reporting/blocking, and legal review for India.
